#### Priority Issues

* **[P1] Missing `rel="noopener"` on Target="_blank" Links**
  * **Why it matters**: Exposes the site to security vulnerabilities (tabnabbing) and shares execution threads with external pages.
  * **Fix**: Add `rel="noopener noreferrer"` to all target="_blank" anchors in `index.html`.
  * **Suggested command**: `/impeccable harden`

* **[P1] Accessibility of Empty Decorative Icons**
  * **Why it matters**: Screen readers will read out decorative icon elements (like `ph-airplane-takeoff`), disrupting the layout flow for visually impaired users.
  * **Fix**: Add `aria-hidden="true"` to all `<i>` tags in `index.html`.
  * **Suggested command**: `/impeccable adapt`

* **[P2] Low Color Contrast for Small Text**
  * **Why it matters**: The muted gray text (`#787774`) on the warm bone canvas (`#F7F6F3`) has a contrast ratio of ~3.6:1, falling below WCAG AA minimum of 4.5:1 for body copy.
  * **Fix**: Darken `--color-text-muted` slightly to `#62615E` (~4.8:1 contrast) in `style.css`.
  * **Suggested command**: `/impeccable layout`

* **[P2] Design System Semantic Departure in Terminal**
  * **Why it matters**: The layout uses custom span tags (`class="command"`) instead of `<kbd>` tags as explicitly prescribed in `DESIGN.md`.
  * **Fix**: Modify the terminal display spans to use `<kbd>` tags in `index.html`.
  * **Suggested command**: `/impeccable typeset`
